# Order Types

Ondo Perps supports a full suite of order types designed for both straightforward execution and sophisticated trading strategies.

* **Market Orders**: Execute immediately at the best available price.
* **Limit Orders**: Execute at a specified price or better, resting on the order book until filled or cancelled.
* **Take Profit / Stop Loss (TP/SL)**: Automatically close a position when the mark price reaches a specified level, on either the upside or downside.
* **TWAP**: Divide a large order into smaller child orders executed at intervals over a set duration, reducing market impact.

See Section: Advanced Order Types for a full breakdown.
