资金费用历史

查询合约仓位的历史资金费用记录

限频权重: 20

HTTP请求​

  • GET /api/v1/account/{walletId}/history/funding-rate
请求示例
curl "https://api.popdex.xyz/api/v1/account/0x1234567890abcdef1234567890abcdef12345678/history/funding-rate?startTime=1707264000000&endTime=1707350400000&limit=20"

请求参数​

参数名参数类型是否必须描述
walletIdString是钱包地址（URL路径参数）
startTimeString否开始时间戳
Unix时间戳的毫秒数格式，如 1597026383085
未传时默认为当前时间减30天
仅传 startTime 时，查询范围为 [startTime, min(startTime+30天, 当前时间)]
endTimeString否结束时间戳
Unix时间戳的毫秒数格式，如 1597026383085
未传时默认为当前时间
不能超过当前时间，须晚于 startTime
仅传 endTime 时，查询范围为 [endTime-30天, endTime]
与 startTime 最大间隔90天
cursorString否分页游标，首次请求不传，后续请求使用上次返回的 cursor
limitString否每页条目数，默认 20，最大 100
symbolString否交易对名称，例如：BTCUSDC
positionSideString否持仓方向，Long 多仓 / Short 空仓
返回示例
{
  "code": "200",
  "msg": "success",
  "data": [
    {
      "symbolId": "1",
      "symbol": "BTCUSDC",
      "positionSide": "Long",
      "marginMode": "Isolated",
      "createdAt": "1707264000000",
      "createdBlock": "123456",
      "holdQty": "1.2345",
      "fundingFee": "2.2345",
      "fundingRate": "0.000012"
    }
  ],
  "cursor": "2",
  "total": "100",
  "limit": "20"
}

返回参数​

返回字段参数类型字段说明
codeString响应码
msgString返回信息
cursorString下一页游标，无更多数据时为空
totalString总记录数
limitString本次返回条目数
dataList<Object>资金费用记录列表
> symbolIdString交易对ID
> symbolString交易对名称
> positionSideString持仓方向
Long 多仓
Short 空仓
> marginModeString保证金模式
Isolated 逐仓 / Cross 全仓
> createdAtString资金费用结算时间戳，Unix毫秒
> createdBlockString结算时对应的区块高度
> holdQtyString结算时持仓数量
> fundingFeeString资金费用，正数表示用户收取，负数表示用户支付
> fundingRateString结算资金费率
