分页查询站内信消息

分页拉取站内信时间线（cursor + limit）。与分类汇总接口成对：feed 拉消息，categories 拉分类行。传入 walletId 时可用 businessType 查询参数按业务类型筛选（与交易接口的 category 产品类型无关），取值与 categories 返回的 data 中 businessType 枚举一致；未传 walletId 时返回公开消息（如公告），无需登录。

限频权重: 10

HTTP请求​

  • GET /web/v1/msg/station/feed
  • GET /app/v1/msg/station/feed
请求示例
# Web：传入 walletId
curl "https://api.popdex.xyz/web/v1/msg/station/feed?walletId=0x1234567890abcdef1234567890abcdef12345678&businessType=Trade&cursor=0&limit=20" \
  -H "language: zh_CN"

# App：传入 walletId
curl "https://api.popdex.xyz/app/v1/msg/station/feed?walletId=0x1234567890abcdef1234567890abcdef12345678&businessType=Trade&cursor=0&limit=20" \
  -H "language: zh_CN"

# Web：公开消息（不传 walletId）
curl "https://api.popdex.xyz/web/v1/msg/station/feed?cursor=0&limit=20" \
  -H "language: zh_CN"

# App：公开消息（不传 walletId）
curl "https://api.popdex.xyz/app/v1/msg/station/feed?cursor=0&limit=20" \
  -H "language: zh_CN"

请求参数​

参数名参数类型是否必须描述
walletIdString否钱包 id。传入时返回该钱包站内信；未传时仅返回公开消息
0x1234567890abcdef1234567890abcdef12345678
businessTypeString否业务类型，仅在有 walletId 时生效。All 或未传：全部；Trade / Account / Announcement：仅该类型；与 categories 的 businessType 枚举一致
cursorString否分页游标，第一页传 0，后续传上一次响应的 cursor
limitString否每页数量，默认 20，最大 100

Header 参数​

参数名参数类型是否必须描述
languageString否语言 locale，如 zh_CN、en_US；未传时服务端默认 zh_CN
返回示例
{
  "code": "200",
  "msg": "success",
  "data": [
    {
      "id": "194001",
      "title": "订单成交提醒",
      "content": "您的订单已成交",
      "sendTime": "1713400000000",
      "openUrl": "app://order/detail?id=1001",
      "businessType": "Trade",
      "txHash": "0x7a250d5630b4cf539739df2c5dacb4c659f2488d89b4b8f4c5c7c8c3c2c1c0b9a8"
    }
  ],
  "cursor": "20",
  "total": "100",
  "limit": "20"
}

返回参数​

返回字段参数类型字段说明
codeString响应码
msgString返回信息
cursorString分页游标，用于获取下一页
totalString总记录数
limitString每页数量
dataList<Object>消息列表
> idString消息 ID
> titleString消息标题
> contentString消息内容
> sendTimeString发送时间，Unix 时间戳的毫秒数字符串
> openUrlString点击跳转链接
> businessTypeString单条消息的业务类型：Trade / Account / Announcement
> txHashString链上交易哈希；无链上关联时为空字符串
