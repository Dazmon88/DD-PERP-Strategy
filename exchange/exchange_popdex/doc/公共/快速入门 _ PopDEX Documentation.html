快速入门

接入准备​

PopDEX 是一个非托管 DEX，您通过 EVM 兼容钱包连接，资产始终由您的钱包控制。

要使用私有 API 接口，请先在网页端连接钱包，然后创建 Agent Key 以授权程序化访问您的账户。

鉴权​

PopDEX 使用基于钱包的鉴权模型，而非传统 API Key 方式。

公共接口​

公共接口（行情数据、交易所信息等）无需鉴权，仅需携带 Content-Type 请求头即可调用。

私有接口​

私有接口通过请求路径中嵌入的钱包地址识别账户（如 /api/v1/account/{walletId}/...）。

写操作（下单、撤单、改单）需在请求体中携带链上签名。签名由已在链上完成授权的 Agent Key 生成，代表您的账户执行操作。

Agent Key​

Agent Key 是一个 secp256k1 密钥对，您在链上授权其以您的名义签署交易操作。创建步骤：

  1. 使用钱包登录网页端。
  2. 进入账户设置，创建 Agent Key。
  3. 通过您的主钱包提交链上授权交易。
  4. 使用 Agent Key 对写接口的请求消息进行签名。

每个账户最多可持有 10 个 Agent Key。密钥可授权访问所有子账户或限定在某个指定子账户，并可随时撤销。详情请参阅 Agent Key。

EIP-712 签名域​

PopDEX 上所有 EIP-712 类型数据签名均使用以下域。主网与测试网的 name 字段不同。

主网：

字段值
nameMorph Tachyon
version1
chainId2184
verifyingContract0x0000000000000000000000000000000000000000

测试网：

字段值
nameMorph Tachyon Testnet
version1
chainId34952
verifyingContract0x0000000000000000000000000000000000000000

JSON 格式如下：

主网
{
  "name": "Morph Tachyon",
  "version": "1",
  "chainId": 2184,
  "verifyingContract": "0x0000000000000000000000000000000000000000"
}
测试网
{
  "name": "Morph Tachyon Testnet",
  "version": "1",
  "chainId": 34952,
  "verifyingContract": "0x0000000000000000000000000000000000000000"
}

每个需要签名的接口文档中均说明了具体的 primaryType 和消息结构。

域名​

主网和测试网的接口地址请参阅 API 域名。

请求头​

所有 REST 请求必须携带以下请求头：

请求头值
Content-Typeapplication/json

频率限制​

完整规则请参阅频率限制。关键规则：

  • 读接口：基于 IP 的权重系统，每分钟最多 1,200 权重。
  • 写接口（下单、改单、撤单）：基于目标钱包地址限频（非 IP）。基础配额为 10,000，每 1 美元终身交易量额外增加 1 配额。
  • WebSocket：每 IP 最多 10 个连接，所有连接合计最多 1,000 个订阅。
