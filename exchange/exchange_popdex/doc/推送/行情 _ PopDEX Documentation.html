行情

描述​

获取产品的最新成交价、买一价、卖一价和24小时交易量等信息，有变化（成交、买一卖一发）时推送

请求示例
{
    "op": "subscribe",
    "args": [
        {
            "category": "Spot",
            "topic": "ticker",
            "symbol": "BTCUSDT"
        }
    ]
}

请求参数​

参数名参数类型是否必须描述
opString是操作
subscribe 订阅
unsubscribe 退订
argsList<Object>是请求订阅的频道列表
> categoryString是产品线类型
Spot 现货交易
Futures 合约
> topicString是频道名
ticker 行情频道
> symbolString是交易对名称
例如BTCUSDT
订阅返回示例
{
  "event": "subscribe",
  "arg": {
    "category": "Spot",
    "topic": "ticker",
    "symbolId": "1",
    "symbol": "BTCUSDT"
  }
}

返回参数​

返回字段参数类型字段说明
eventString事件
argObject订阅的频道
> categoryString产品线类型
Spot 现货交易
Futures 合约
> topicString频道名
ticker行情频道
> symbolIdString交易对ID
> symbolString交易对名称
errCodeString错误码，失败时返回
msgString错误消息，失败时返回

推送数据参数​

返回字段参数类型字段说明
tsString时间戳
blockNumberString系统生成数据时的塊高
argObject订阅成功频道
> categoryString产品线类型
Futures 合约
> topicString频道名
ticker行情频道
> symbolIdString交易对ID
> symbolString交易对名称
actionString推送数据动作
update 增量
dataObject订阅的数据
> categoryString产品线类型
Futures 合约
> symbolIdString交易对ID
> symbolString交易对名称
> highPrice24hString24小时最高价
> lowPrice24hString24小时最低价
> openPrice24hString24小时前的市场价格
> lastPriceString最新价
> turnover24hString24小时成交额
> volume24hString24小时成交量
> bid1PriceString买一价
> ask1PriceString卖一价
> bid1SizeString买一量
> ask1SizeString卖一量
> price24hPcntString24小时价格涨跌幅
> indexPriceString指数价格(只有合约返回)
> markPriceString标记价格(只有合约返回)
> fundingRateString当前资金费率(只有合约返回)
> nextFundingTimeString下次资金费率结算时间(只有合约返回)
> openInterestString当前平台总持仓量(只有合约返回)
> statusString交易对交易状态
